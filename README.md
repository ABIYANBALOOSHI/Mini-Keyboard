# 5-Key Macro Keyboard

A custom-designed 5-key mechanical macro keypad powered by a Seeeduino XIAO RP2040, built for the Hack Club Forge submission.

## Overview
This project is a compact, programmable 5-key macro pad designed from scratch using KiCad. It features 5 Cherry MX mechanical switches, a custom diode matrix using SOD-323 diodes, and a Seeeduino XIAO RP2040 microcontroller mounted via a 7-pin header.

## Features
* **Microcontroller**: Seeeduino XIAO RP2040 for high performance and easy programmability.
* **Switches**: 5x Cherry MX mechanical switches with custom routing.
* **Protection**: SOD-323 diodes to prevent ghosting and ensure precise input registration.
* **Design**: Fully designed, routed, and DRC-verified in KiCad.
